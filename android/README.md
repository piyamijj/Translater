# android/ — Capacitor native project

This directory is intentionally **not** hand-written. A Capacitor Android
project (Gradle wrapper, `AndroidManifest.xml`, `MainActivity`, resource
folders, etc.) must be generated by the actual Capacitor CLI (`npx cap add
android`) against the exact `@capacitor/core` / `@capacitor/android` versions
in `package.json` — hand-authoring it risks a subtly broken/non-buildable
project that silently drifts from whatever Capacitor version is installed.

The `build-apk` GitHub Actions workflow (`.github/workflows/build-apk.yml`)
handles this automatically and idempotently:

1. On every run, if `android/app` doesn't exist yet, it runs
   `npx cap add android` to generate a fresh, correct native project for the
   currently installed Capacitor version, then commits it back to the
   repository so it becomes a normal, version-controlled part of the repo
   from that point on (exactly like the project structure calls for).
2. It then runs `npx cap sync android` to copy the latest static web build
   (`out/`) into the native project and syncs any Capacitor plugins.
3. Finally it builds the APK with Gradle and publishes it to GitHub Releases.

If you want to inspect or customize the native project locally, run:

```bash
npm install
npm run build:capacitor
npx cap add android   # only if android/app doesn't exist yet
npx cap sync android
npx cap open android   # opens Android Studio
```
